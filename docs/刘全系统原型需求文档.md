## 1. 系统概述

刘全是一个 **Etsy 综合智能运营系统**，通过 AI 大管家盯着店铺的生意事实（订单/库存/客户/流量），主动判断该做什么，变成任务派给团队，人做完结果回流，AI 判断下一步，循环往复。

### 1.1 技术栈

- **后端**: FastAPI + SQLAlchemy 2.0
- **前端**: Jinja2 + HTMX + Tabler 1.4
- **数据库**: PostgreSQL 16（双 database：业务库 + 引擎库）
- **AI**: PydanticAI + DeepSeek
- **部署**: 阿里云（与 NocoBase 同机）

### 1.2 架构分层

```
L1 业务应用层（TM 任务中心 / CRM / ERP 只读增强 / SEO / 扒图）
    ↓  统一契约：Event / Context / Action / Task
L2 AI 引擎层（liuquan-engine）
    ↓  PydanticAI
L3 模型层（DeepSeek）
L0 数据层（PG16 单实例双 database）
```

## 2. 功能模块

### 2.1 TM 任务中心

**目标**: AI 建议自动变任务，人工处理完回流

**功能**:
- 任务列表（支持筛选：状态/来源/标签）
- 任务详情（内容/来源/状态/截止时间/操作）
- 任务状态流转（待处理→进行中→已完成/已作废）
- 任务步骤（轻量子任务）
- 任务派生（快速建关联任务）
- AI 提案审核（依据强制展示，禁幻觉）

**页面布局**:
- 左侧：筛选面板（状态/来源/标签）
- 右侧：任务列表表格

### 2.2 CRM 客户关系管理

**目标**: EOMS 已验证的 CRM 链路在刘全跑通

**功能**:
- 客户列表（搜索/头像/未读标记/店铺来源）
- 对话区（多语言消息/AI 翻译/系统提示）
- 粘贴对话（历史记录入口）
- 快照生成
- 待办生成（AI 建议 → 人工审核 → 生成任务）
- 飞书通知

**页面布局**:
- 左侧：客户列表（320px）
- 右侧：对话区（消息流 + 输入框）

### 2.3 SKU 建档（v0.7）

**目标**: 把素材库的图加工成「对内能管理库存销售、对外能上架」的档案

**功能**:
- SKU 列表（卡片网格展示）
- SKU 详情（商品代号/名称/规格属性/图集/库存）
- 编号自动生成（类型前缀 P/C/U + 商品代号 + 序号）
- 规格属性 specs（键值对）
- 图库文件夹浏览器 + 标签搜索 + 上传入口
- 建档后可编辑

**页面布局**:
- 卡片网格展示（每卡片：编号/名称/规格/库存/状态）

### 2.4 ERP 只读增强

**目标**: NocoBase 只读视图 + 定价建议

**功能**:
- 货品建档
- 库存管理
- 补货建议
- 异常预警
- 生产库存只读

**页面布局**:
- 导航归 ERP 一级菜单
- 四个子页面：货品建档/库存管理/补货建议/异常预警

### 2.5 SEO 工具

**目标**: Etsy SEO 优化

**功能**:
- 关键词研究
- 标题优化
- 标签优化
- 健康检查
- 定时链

### 2.6 扒图/素材库（v0.6）

**目标**: 链接采集/图片管理

**功能**:
- 链接采集（立即扒/定时队列）
- 图片管理（文件夹式浏览）
- 夸克上传
- 元数据（meta.txt）

### 2.7 设置页

**目标**: 系统配置管理

**功能**:
- 店铺管理（名称/备注/状态）
- AI 设置（API 密钥/模型选择/风格指南/术语表）
- 定时任务（定时链清单/开关/运行时间）
- 通知配置（飞书 webhook/通知开关）
- 系统参数（跟进天数/逾期天数/列表分页等）

**页面布局**:
- 左侧：设置导航（分组菜单）
- 右侧：设置内容（独立提交 + HTMX 局部刷新）

## 5. 数据模型

### 5.1 任务 (tm.task)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| title | VARCHAR | 任务标题 |
| content | TEXT | 任务内容 |
| domain | VARCHAR | 来源域 (crm/erp/seo/tm) |
| status | VARCHAR | 状态 (open/in_progress/done/void) |
| source_type | VARCHAR | 来源类型 (ai/manual/schedule) |
| source | JSONB | 来源信息 (含 customer_id 等) |
| tags | JSONB | 标签数组 |
| due_date | DATE | 截止日期 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 5.2 客户 (crm.customer)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | VARCHAR | 客户名称 |
| shop | VARCHAR | 店铺来源 |
| status | VARCHAR | 状态 (active/archived/on_hold) |
| last_message_at | TIMESTAMP | 最后消息时间 |
| created_at | TIMESTAMP | 创建时间 |

### 5.3 SKU (business.sku)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| product_code | VARCHAR | 商品代号 |
| name | VARCHAR | SKU 名称 |
| specs | JSONB | 规格属性 (键值对) |
| stock | INTEGER | 库存数量 |
| status | VARCHAR | 状态 (active/inactive/out_of_stock) |
| images | JSONB | 图集 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

## 7. 交互说明

### 7.1 任务状态流转

```
待处理 → 进行中 → 已完成
  ↓         ↓
已作废   已作废
```

### 7.2 AI 提案审核流程

1. AI 生成待办候选（带 evidence 依据）
2. 人工审核（依据强制展示）
3. 确认后生成 TM 任务
4. 任务出现在任务清单

### 7.3 CRM 对话流程

1. 粘贴对话文本
2. AI 自动翻译 + 生成快照
3. AI 生成待办建议
4. 人工审核确认
5. 生成 TM 任务
