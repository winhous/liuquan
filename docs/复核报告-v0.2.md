## 二、页面复核操作路径（按顺序走一遍）

1. **登录**：打开 http://127.0.0.1:8090 → 密码 `liuquan` → 选「运营」→ 进入任务中心
2. **看任务列表**：真数据任务表（来源徽章=域、逾期标红、无优先级列）、顶部逾期提醒条
3. **看提案待审核**：侧栏提案带依据区（类型/ref_id/原文摘录）+ 来源（链+引擎任务 id）
4. **触发演示链**：点「触发演示链」→ 选 tm_demo_chain → 填示例输入 → 提交 → 数秒后新提案出现在待审核栏（引擎真调 DeepSeek，可查审计）
5. **批准提案**：点「批准」→ 提案转任务进清单（标「AI 建议」来源）
6. **完成任务**：点「完成」→ 弹窗不填回复点确定被拒 → 填回复 → 成功（状态变已完成）
7. **试其他**：新建任务（人工通道）/ 编辑 / 派生 / 重开 / 筛选

```bash

curl -X POST http://127.0.0.1:8100/api/engine/tasks \
  -H "Content-Type: application/json" \
  -d '{"chain_id":"tm_demo_chain","input":{"text":"买家询问物流时效","ref_id":"msg-001","kind":"message"},"trigger_ref":"运营"}'
```
