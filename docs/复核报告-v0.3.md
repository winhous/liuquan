## 二、页面复核操作路径

1. **登录**（http://127.0.0.1:8090，共享密码）→ 任务中心
2. **CRM 客户列表**（左侧导航 CRM）：状态筛选 tab / 搜索 / 新建客户（重名提示）/ 删除（二次确认）
3. **客户详情**：三行布局（快照 / 粘贴+回复台 / 时间线 + 待办候选 + 任务卡）
4. **粘贴对话**（历史记录同一入口）：粘贴英文对话 → 自动翻译 + 快照更新 + 待办候选（带依据）——异步轮询不卡页面
5. **确认候选** → 任务出现在任务中心（来源徽章 CRM + 标签）
6. **回复台**：auto/points/literal 三模式 → 双栏预览 → 已发送归档
7. **翻译工具**（对话翻译子页）：任意文本翻译 → 复制 → 可选归入客户
8. **任务下一步**：AI 建议卡 + 同意/改派/忽略 + 自然语言输入（如「流转到 ERP 库存」→ 解析 → 确认；ERP 未接入会提示）
