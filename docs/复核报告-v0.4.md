3. **CRM 客户列表**：新建客户表单「来源店铺」改为下拉（启用中店铺 + 可留空）
4. **设置 → AI 设置 → API 密钥**：填写保存 → 写 .env（只显示已配置/未配置，不回显密钥）+ 提示重启引擎生效；HTMX 局部刷新该卡片
5. **设置 → 系统设置 → 系统参数**：七键清单（跟进天数/每页条数/定时默认时间/引擎参数/通知开关），每键一行独立保存（改一键只刷新该行、只更新该 key）
6. **设置 → 系统设置 → 定时任务**：种子链「CRM 未跟进提醒」（每天 07:00）+ 新增链（选引擎注册表链 + 时间）+ 启停/改时间/立即运行；引擎未连接时降级提示
7. **设置 → 系统设置 → 通知配置**：飞书通知总开关 + webhook URL（写 .env）
8. **任务中心**：定时提醒任务自动就位（标题「跟进客户：XX（已 N 天未跟进）」+ 来源 CRM）
