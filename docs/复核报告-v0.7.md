## 一、本版交付什么

**建档 = 建货档案**（用户拍板的最终模型，无"品"实体）：
- **实物档案 physical**：仓库里采购来的一件货（红机/蓝机/普通盒/精装盒…），有库存有成本——真 SKU
- **组合档案 combo**：组合编码（精装红 = 红机×1+精装盒×1…），Etsy 填一个 SKU 框，系统里是配方，BOM 展开扣子件库存——不是真 SKU
- **定制档案 custom**：CUSTOM 占位，无库存、成本可空、接单生产（订单内容 v0.9 才处理）
- 商品名（打火机）= 归类文本，不是实体；**商品代号**（LTR）= 同组英文短码，用于自动编号
- **编号自动生成**：P/C/U（实物/组合/定制）-代号-序号（如 P-LTR-001，同商品第二档 P-LTR-002）；可手改覆盖，查重+格式保留；在售/下架不编入号码（状态看徽章/筛选）
- **规格属性 specs**：每档键值（颜色/尺寸…），为 v0.8 卖法层 + Etsy 变体映射铺路
- **建档后可编辑**（基础字段/商品组迁移/规格；kind 锁定；combo 配方下架后可改）
- **图**：档案图库 + 建档选图 = 图库浏览器（文件夹列表点进加载 + 搜索支持图片标签 + 本地上传入口）+ 足迹软提示
- **库存**：建档页不展示；库存在 ERP→库存管理（结存/入出库/流水）；sale 留 v0.9
- 写接口唯一通道：人（页面）与 AI（引擎）都走 /api/biz/* + 同一 service 校验
