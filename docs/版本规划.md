# 刘全版本规划

> 版本号 = 系统能力里程碑，标记"刘全能做什么"的跃迁。
> 本文档不做待办堆叠（待办进详设与变更日志），只维护版本里程碑。

## 版本号三条规矩

1. 发版必须 git 落地（tag + commit），否则不算发版
2. 业务工序增量（新工序/工序改造）不绑版本号，只进变更日志，做完即用
3. 一版验收标准全达成并验证 = 可发版；未达不发，不允许"部分完成的版本"

## 各版本定义

### v0.1 引擎地基

**目标**：引擎最小内核命令行跑通一个工序，全程可审计。

**范围**：5 相位状态机、PydanticAI 接入（DeepSeek）、工序注册表（YAML + 拒载）、审计落库、检查点。一个演示工序。

**验收**：
- 命令行提交工序任务 -> 状态机全相位走完 -> DONE
- 注册表缺字段拒载（反向测试覆盖）
- 审计可查输入/输出/token/耗时
- 中途 kill，重启后从检查点续跑

### v0.2 TM + 引擎接通

**目标**：AI 建议自动变任务，人工处理完回流。

**范围**：PG16 双 database（业务库 + 引擎库）、任务队列（SKIP LOCKED）、TM 数据模型、TaskProposal 审核流（无优先级分级，决策 11 修订）、FastAPI 骨架 + 共享密码登录（三角色）+ 工作台占位（决策 15）。**任务生成双通道 + 审核依据强制 + 禁幻觉（决策 16）与任务生命周期（决策 17，2026-08-28 并入详设 v0.2）。**

**验收**（2026-08-28 全部达成，A12-A26 断言全绿）：
- [x] 触发工序链 -> 产出提案 -> 全部进审核页 -> 人工批准后成任务
- [x] 人工处理 -> 状态回流引擎可见（task_event 流水 + 追溯闭环）
- [x] 引擎三接口（建任务/查任务/查注册表）可用
- [x] 禁幻觉三件套（机器校验拒落）+ 必填回复 + 派生 + 防重 + 逾期提醒 + 编辑（决策 16/17）

### v0.3 CRM 平移

**目标**：EOMS 已验证的 CRM 链路在刘全跑通，体验不倒退。

**范围**：翻译/快照/回复/待办四工序平移（调用层换 PydanticAI）、CRM 页面、~~EOMS SQLite 数据迁移~~（决策 20 取消）、飞书通知、任务标签 + 流转机制、业务写入接口化（决策 26）。复核反馈 #6 增：任务步骤（轻量子任务，task_step 表 + 完成守卫）。

**验收**（2026-08-30 全部达成，A27-A37 断言全绿 + 复核反馈 #1-#6 处理）：
- [x] 粘贴对话 -> 翻译+快照+待办自动跑完，端到端 <= 6s（实测 ≈4.3s，EOMS 基线 5.8s）
- [x] 待办出现在 TM 清单（标来源 CRM；source.customer_id 关联客户）
- [x] 存量数据不迁移（决策 20），从零录数据
- [x] 广成电脑关机不影响（链路全程云上）
- [x] 复核反馈 #1-#6：任务清单固定高度+滚动 / 完成作废去编辑 / 按钮统一 btn-sm / 派生 422 修复 / 任务步骤 / 派生弱化（link_parent 默认关）+ 逾期筛选布局修复

### v0.4 定时闭环 + 设置页（配置地基）

**目标**：先立"配置地基"（settings 表：读配置先查表、表无回退默认，杜绝硬编码继续滋生），同时让系统第一次不需要人触发自己干活。

**范围**（决策 33/34/35/36，2026-08-30 用户拍板）：
- **settings 表（配置地基）**：键值对配置表；导航一级「设置」
- **导航与交互形态（决策 36 修订）**：一级「设置」下每个设置项 = **独立二级菜单**；**AI 设置 = 分组标题（不可点，纯分组）**，其下 API 密钥/模型选择/风格指南术语表是**真正的叶子菜单**（不用 TAB 页；Tabler nav-group 实现）；**独立提交机制**——每个设置块独立小表单 + 独立接口 + HTMX 局部刷新，settings 表按 key 原子更新（改 API 只提交 API）
- **设置页内容**：
  - ① 店铺管理：店铺表（名称/备注/启用停用）+ 管理页（每条独立存），CRM source_shop 下拉候选
  - ② AI 设置（**分组标题不可点，下挂叶子菜单**：API 密钥 / 模型选择 / 风格指南术语表）：**v0.4 只做 API 密钥**（底层仍存 .env，R20 密钥不进数据库——页面是写 .env 的友好壳）；其余叶子占位，后续慢慢加
  - ③ 定时任务模块：定时链清单（每条链独立存/独立开关）
  - ④ 通知配置：飞书 webhook 页面化（决策 21 留账，现 .env）+ 通知开关
  - ⑤ 系统参数：跟进天数/逾期天数/列表每页条数/定时链默认时间等现有硬编码全量搬 settings 表（每个键独立存）
  - ~~⑥ 登录密码、角色~~：**v0.4 不做**（决策 36 撤销，随 v0.7 权限系统）
- **定时触发底座**（引擎）：schedule 表 + 调度器 + 去重（同一业务对象当天不重复触发）；事件触发/配额记账不做（用不到就不做，留底座扩展位）
- **首批定时链 1 条**：CRM 客户超 N 天未跟进提醒（每天自动跑 → 提醒任务进 TM；N 从 settings 表读）
- 权限系统留 v0.7；SEO/扒图/ERP 全部延后，不进 v0.4

**验收**（2026-09-01 全部达成，A38-A45 断言全绿 + 集成验收真跑）：
- [x] 设置页可配置并生效（店铺增删改、API 密钥写 .env、定时链清单、飞书 webhook、系统参数七键）
- [x] **独立提交生效**：改某一项只调该项接口、只更新该 key（其他 key updated_at 不动）、页面 HTMX 局部刷新该块（A41）
- [x] 现有硬编码（FOLLOW_UP_DAYS/page_size/引擎参数）已搬 settings 表，代码无新增硬编码参数（A38）
- [x] 定时任务自动跑（调度器 tick 到点触发 + 漏跑补跑 + 种子链开箱可用）；「立即运行」真跑：提醒任务就位在 TM（标来源 CRM）
- [x] 同一客户当天重复触发只生成一次（写接口防重 409，集成验收实锤：再次运行任务数不增）
- [x] 调度器崩溃重启后不漏跑/不重跑（last_run_at 锚点 + 漏跑补跑测试覆盖）
- [x] 四绿全绿（746 passed，无 skipped）+ 验收断言 A1-A45 全绿
