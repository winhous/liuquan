## 5. 引擎 connector 层（新，`engine/connectors/`）

**设计**：工序不直连外部（R11 精神 + 广成「外联 connector」先例）。connector = 外部资源封装（HTTP/CDP/浏览器/本地 vendor），工序内只按 id 引用。**技术摸底关键结论：eHunt CDP 通道无 API 端点（llms.txt 确认），只能进程式连接器连 9222 调试 Chrome——刘全 web 读接口机制无法替代，必须保留引擎侧 connector（§5.2）。**

```text
engine/connectors/
├── __init__.py        # 注册表 CONNECTORS: id -> factory + get_connector(id, ctx) 原语
├── ehunt_api.py       # ehunt_api：eHunt API 通道（竞品画像）——照搬广成 ehunt_connector.py
├── ehunt_keyword.py   # ehunt_keyword：CDP 9222 逐词指标——适配改造广成 ehunt_keyword_connector.py
├── xhs.py             # xhs：小红书扒图——照搬广成（XHS-Downloader vendor）
├── xianyu.py          # xianyu：闲鱼扒图——照搬广成（playwright 无头）
└── http_image.py      # http_image：普通图片 URL 下载（CRM 对话图片用，新增）
```

- **EngineContext 增字段** `connectors: dict[str, Any]`（runner ACT 装配时注入；无 connector 实现/未配置时缺失键 = 工序内降级，不注入即 {}）
- **Key 纪律**：EHUNT_API_KEY / VISION_API_KEY 等只进 .env（R20/P2），connector 读法照 engine/core/llm/models_config.py 的 env: 模式（读 os.environ，加载期由入口 dotenv 装载）
- **可用性**：未配置 key / vendor 缺失 / Chrome 未起 → 返回降级结构（ok=False + note），不抛穿链（照广成先例：CDP 不可用不 failed）

### 5.1 ehunt_api（照搬广成 runtime/ehunt_connector.py）

- POST `api.ehunt.ai/api/v1/items`，`X-VIP-TOKEN` 鉴权（.env `EHUNT_API_KEY`，值从广成 .env 复制）；纯 urllib 零依赖
- **UA 伪装必做**：`Mozilla/5.0 (X11; Linux x86_64) ...`（eHunt WAF 拦 python-urllib 默认 UA 直接 403）
- 响应 `{code, data: {product_num, list: [title/price/sales_total/reviews/favorites/tags/store_name]}, quota: {used_today, remaining_today}}`
- 两道闸：8 词硬顶（keywords[:8]）+ page_size≤100（默认 10）；429 = 当日配额耗尽 → 降级 `{ok: False, note: "配额耗尽…"}`，不抛穿链
- 记账：**透传服务端 quota 回显**（§9），无本地账本

## 9. eHunt 配额记账（技术摸底修正：服务端记账回传，无本地账本）

- **记账点**：eHunt 服务端（每条商品 1 积分、200 条/天，响应回传 `quota.used_today/remaining_today`；429 = 当日耗尽）——**唯一记账点**
- **透传链**：ehunt_api connector 返回 quota → keyword_research / listing_healthcheck 工序透传 → 落 `seo.keyword_metric.quota` JSON + 关键词研究页展示（今日已用/剩余）+ 引擎审计可查
- **超限行为**：429 / remaining 不足 → connector 降级 `{ok: False, note: "eHunt 配额耗尽：今日已用 X/200"}`，工序输出降级 + metrics_note，链不失败
- **超限排队**：本版不设自动排队重试（配额按天重置，次日自然恢复）；建设方案「超限排队」验收项解释为本降级行为 + 次日自动恢复
- 客户端两道闸保留：8 词硬顶 + page_size≤100（防误用打爆配额，照广成）
