# 部署：v0.5 外部依赖（扒图 / eHunt CDP / 识图）

> 本文档说明 v0.5（SEO + 扒图）集成验收与部署前需要落地的外部依赖。
> 原则：**代码全部入库，外部资产（vendor/浏览器/密钥）不入库**，按本文档部署时落地。

## 1. eHunt API key（已就绪）

- `EHUNT_API_KEY`：已从广成 `.env` 复制进刘全 `.env`（2026-09-03，值未打印，R20 密钥只进 .env）
- 用途：`engine/connectors/ehunt_api.py`（X-VIP-TOKEN 鉴权，POST api.ehunt.ai/api/v1/items）
- 配额：200 条/天，服务端记账回传（详情见详设 v0.5 §9）

## 2. eHunt CDP 调试 Chrome（关键词逐词指标必需）

- **前置**：`scripts/ehunt-chrome.sh`（已平移自广成）启动 9222 调试 Chrome
  - 持久 profile：`~/.local/share/ehunt-chrome-profile`（复用广成时期登录态，首次需人工确认登录 ehunt.ai）
  - 幂等探活：已运行则跳过
- **用途**：`engine/connectors/ehunt_keyword.py`（playwright connect_over_cdp(9222) 读 keyword-tool 页）
- **注意**：CDP 无 API 端点可替代（llms.txt 确认），必须保留进程式连接器；失败自动降级（metrics_note）不阻塞
- 启动：`bash scripts/ehunt-chrome.sh`（本机无显示环境需 xvfb 或已有 X session；广成先例直接起）
- **无显示/受限环境**（如 CI/容器/开发沙箱）：google-chrome 可能 SIGTRAP 崩溃——需 `xvfb-run -a` 包裹或加 `--no-sandbox`（容器常见）；9222 起不来时 keyword_research 自动降级（仅 API 通道，metrics_note），不影响主链路

## 3. Playwright + Chromium（闲鱼扒图 / eHunt CDP 共用）

```bash
uv add playwright
uv run playwright install chromium      # 下载浏览器（约 150MB，首次）
uv run playwright install-deps chromium # 系统依赖（如缺）
```

- 用途：`engine/connectors/xianyu.py`（闲鱼无头扒图）+ `engine/connectors/ehunt_keyword.py`（CDP 复用系统 Chrome，playwright 库本身必需）
- 测试环境不依赖（fake connector 零网络，四绿已全绿）；**集成验收真跑前必须装**

## 4. XHS-Downloader vendor（小红书扒图，186MB 不入库）

## 5. 识图模型（CRM 对话图片识图 / 可选选品理解）

- 设置页「设置 → AI 设置 → 模型选择 → 识图模型」填写：
  - API Key → 写 .env `VISION_API_KEY`
  - 接口地址 → 写 .env `VISION_BASE_URL`（可空，默认 dashscope 兼容地址）
  - 模型下拉 → settings 表 `ai.vision_model`（默认 qwen-vl-max，可改 qwen-vl-plus / glm-4v）
- **未配置时降级**：vision 别名 optional（models.yaml），runner REASON 识别未配置 → 链不失败，识图文本留空，图片仍下载展示（验收 A54 已覆盖降级路径）
