## 3. 端到端验收流程（每步 = 一个验收点）

> 浏览器操作路径（web 8090 登录后）；每步同时给「单测等价验证」（已绿，可随时回放）。

### 步骤 1：贴链接 → 立即扒（A57 真跑 / A29 无关本步）

- 操作：扒图页区块 A 粘贴框输入真实分享链接（每行一个）→ [立即扒] → 页面轮询 → 素材库区块出现该链接行。
- 验收点（对照 A57/A59）：
  - 链接行状态 **done**、图数 > 0、批次 = web 生成 batch_id；同链接（不同 xsec_token）再贴 → 不重复建行（A59 幂等）。
  - 点「详情」：图片网格显示宽高/水印标记/来源标记徽章（**扒图**，source_mark=scraped）；元数据 desc/tags/作者 可见。
  - 失败可见（A68）：xsec_token 过期链接 → 行状态 failed + error_note「xsec_token 过期…」；元数据缺失 → degraded_note 灰字。
- 单测等价：`uv run pytest "tests/test_acceptance_v06.py::test_a57_scrape_link_to_link_record_and_images" tests/test_acceptance_v06.py::test_a68_failure_and_degraded_notes -q`

### 步骤 2：素材库可见 + 图包导出（A60）

- 操作：链接行操作列 [导出] → 下载 zip。
- 验收点：zip 含全部图片 + metadata.json（url/source/source_mark/width/height/watermark/batch_id + 链接字段齐全）。
- 单测等价：`uv run pytest "tests/test_acceptance_v06.py::test_a60_link_export_zip" -q`

### 步骤 3：勾图 → 生成选品建议 → 提案进审核页（A47/A66 真跑）

- 操作：链接详情勾选 2+ 张图 → [生成选品建议] → 轮询 → 顶部「待审核」徽章 +1；打开 设置/TM 审核区（`/tasks` 提案卡）。

- 单测等价：`uv run pytest "tests/test_acceptance_v06.py::test_a47_link_to_image_file_and_proposal_pending" "tests/test_acceptance_v06.py::test_a66_product_suggestion_real_llm" -q`
